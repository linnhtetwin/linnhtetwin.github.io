# Security Policy

## Reporting a Vulnerability

Since this is a personal portfolio website, it relies mostly on static HTML/CSS. However, if you discover any security issues (e.g., exposed PII that shouldn't be, cross-site scripting in the contact forms if added later, etc.):

1.  **Do not** open a public issue.
2.  Please email me directly at [linnhtetwin.rbt@gmail.com](mailto:linnhtetwin.rbt@gmail.com).

I will review the issue and acknowledge your email within 48 hours.
